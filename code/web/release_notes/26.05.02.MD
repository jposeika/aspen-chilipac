## Aspen Discovery Updates
### Koha Updates
- Fix a Koha renewal issue by correcting the isNightlyUpdate condition used during checkout loading. ([DIS-2495](https://aspen-discovery.atlassian.net/browse/DIS-2495)) (*YL*)
- Fix a hold placement issue in Koha 25.11 caused by the item type parameter name changing from item_type to item_type_id.([DIS-2497](https://aspen-discovery.atlassian.net/browse/DIS-2497)) (*YL*)
- Fix bug where Aspen could not properly authenticate with Koha when updating messaging settings ([DIS-2489](https://aspen-discovery.atlassian.net/browse/DIS-2489)) (*JW*)

### ChiliFresh Updates
- Add ChiliPAC settings (enabled, API key) to the ChiliFresh integration settings. (*AP*)
- Allow ChiliFresh settings to be assigned per library, matching how NoveList and Syndetics settings are scoped. (*AP*)
- Add a ChiliFresh Ratings & Reviews setting that replaces Aspen's own user ratings and user reviews with ChiliFresh ratings and reviews. Syndicated and GoodReads reviews are unaffected. (*AP*)
